# Evaluation

The verifier exits nonzero if the exact 70M parameter count, row count,
independent norm reduction, vector decomposition, cumulative regression suite,
or zero-denominator negative control fails.

This route is dedicated to falsification, but its protocol deviations prevent a
negative short-run result from contradicting the paper's exact empirical
statement. The only admissible final verdict is therefore `BLOCKED` unless a
paper-protocol counterexample is obtained.
