# Method

The cumulative node reruns the accepted Claims 1–5 verifier chain under the
unchanged command and pinned lockfile. Each falsification:

1. restates the printed quantified statement;
2. certifies every stated assumption;
3. computes the contradicting quantity;
4. uses an independent symbolic, analytic, high-precision, or complete-Hessian checker;
5. mutates the intended mechanism in a negative control.

Claim 6 is handled by four distinct routes and remains BLOCKED because its
paper-scale protocol is unavailable. Reader-facing evidence is mirrored to
canonical pages and raw JSON; internal run logs are not required for traversal.
