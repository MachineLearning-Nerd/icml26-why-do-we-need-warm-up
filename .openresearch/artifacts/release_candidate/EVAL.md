# Evaluation

The fixed verifier returns nonzero if any cumulative certificate,
counterexample inequality, assumption audit, independent checker, negative
control, or historical regression fails. Publication additionally requires:

- a fresh candidate download;
- canonical-entrypoint traversal;
- protected-old-file subset verification;
- JSON and link validation;
- a text-only allowlist and SHA-256 manifest;
- secret scanning;
- two evaluator-blind reviews, the second after fixes.
